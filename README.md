# Withstand The Horde

**RTS + base-builder de un solo desarrollador.** Levanta una ciudad amurallada,
gestiona recursos y defiende lo que construyes de una horda de hasta **2.500
zombis simulados en la GPU** (compute shader, Godot 4).

## El juego en una frase

Construyes casas, almacenes, granjas y aserraderos; levantas muros y torres;
reclutas soldados. Y entonces llega la horda. La simulación de enemigos corre en
la GPU, así que miles de zombis se mueven a la vez en un portátil normal.

- **Modo Mundo**: campaña con progresión.
- **Modo Infinito**: aguanta todo lo que puedas.
- Control **tiempo real con pausa**.

Hecho por una sola persona en **Godot 4**.

## Código
